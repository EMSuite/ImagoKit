# Status: ImagoKit 0.12.0 <!-- x-release-please-version -->

ImagoKit 0.11.0 (2026-11-16), against NumPy 2.5.4, SciPy 1.18.1 and scikit-image 0.26.0. Live: the FFT surface (`fft2`, `rfft2`, `fftshift`, axes and norm), power spectra and
spot measurement, Gaussian, uniform, difference-of-Gaussians, Butterworth (both with channels) and window filters (every `get_window` family), Fourier and spline-order shifts (constant and wrap modes too), phase correlation (plain and masked), HRTEM filter
steps, `peak_local_max` (footprint, labels, peaks per label), profiles (multichannel too), colormaps, segmentation helpers (thresholds, binary morphology, labelled statistics, `regionprops` completion, areal density, distance transform with indices, watershed with compactness and lines, rolling ball with `nanSafe`), zoom and rotate, TV and non-local-means denoising (multichannel and integer images), real-input 2D and 1D transforms and a mixed-radix Float64 plan, GPA strain (checked on planted fields only), CSV export. Parity: `docs/parity.md` (93 rows: 36 present, 12 partial, 45 missing); timings against Python:
`docs/benchmarks.md`; what is open: the GitHub issues (the upsampled registration, `label`, Metal paths); known limits: `docs/parity.md`.

Since 0.8.0: 0.9.0 (2026-10-31) closed the gaps named above and renamed the slice pins by subject; 0.9.1 (2026-11-01) made the CSVs quote the reader note; 0.9.2 and 0.9.3 (2026-11-12, 2026-11-13) halved the memory of a 2D FFT of any size, made public calls refuse bad parameters instead of trapping, and held the aligned float32 stack sum to NumPy's accumulation; 0.10.0 (2026-11-14) counts an 8-bit or 16-bit histogram on its stored values and runs the 2D FFT on every core; 0.10.1 (2026-11-14) peaks a real image's power spectrum at half the memory; 0.11.0 (2026-11-16) stops long operations when their task is cancelled. `TidyResultsCSV.unvalidatedClause`, deprecated and written by no writer, is gone. Details and the migration notes: `CHANGELOG.md`.

Test split: the comparisons with the pinned NumPy, SciPy and scikit-image values and the benchmark harness are the `ImagoKitParityTests` target (fixtures stay in `Tests/Imago*Tests/Fixtures`, found through `ImagoKitTestSupport`); `swift test -c release --parallel --skip ImagoKitParityTests` runs the fast unit tests (what every pull request runs), the plain `swift test -c release --parallel` the full suite (before a release and nightly). On an Apple Silicon Mac, release, warm build, the fast target takes about 2 s and the full suite about 5 s.
